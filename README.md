# Мудрость нахуй не денешь — автопубликация ВКонтакте

Сообщество: https://vk.ru/forty666  
ID сообщества: 73387436

GitHub Actions публикует 10 коротких авторских мыслей в день. Каждый пост содержит одно предложение и три разных хэштега. История сохраняется в `post_history.json` для защиты от повторов.

## GitHub Secrets

В Settings → Secrets and variables → Actions добавьте:

- `VK_ACCESS_TOKEN` — токен сообщества ВК с разрешением на публикацию на стене.
- `VK_GROUP_ID` — `73387436`.

Токен не добавляйте в файлы репозитория и не отправляйте в чат.

## Расписание

Время московское (UTC+3): 08:00, 09:30, 11:00, 12:30, 14:00, 15:30, 17:00, 18:30, 20:00, 21:30.

GitHub Actions может запускать cron с задержкой. В публикации используется идентификатор расписания, поэтому задержка не должна приводить к выбору другого слота.

## Ручной запуск

Actions → Daily VK wisdom → Run workflow. Повторный запуск уже опубликованного слота будет пропущен.
